# Guide de Contribution - Kick Flight: Reborn

Merci de votre intérêt pour contribuer à Kick Flight: Reborn ! 🚀

## Comment contribuer

### 1. Développement
- Cloner le repository
- Créer une branche pour votre feature
- Soumettre une Pull Request

### 2. Game Design
- Proposer des idées de Kickers
- Suggérer des mécaniques de gameplay
- Designer des arènes

### 3. Art & Assets
- Concepts art des personnages
- Modèles 3D
- Animations
- Effets visuels

### 4. Documentation
- Améliorer la documentation
- Traduire en différentes langues
- Créer des tutoriels

### 5. Testing
- Rapporter des bugs
- Tester les nouvelles features
- Feedback sur le gameplay

## Code de conduite

- Respecter tous les contributeurs
- Critiques constructives uniquement
- Pas de toxicité
- Focus sur la préservation de l'esprit du jeu original
