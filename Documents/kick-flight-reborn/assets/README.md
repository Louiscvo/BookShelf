# Assets

Assets du jeu (modèles 3D, textures, audio, etc.)

## Structure recommandée

- **Models/** - Modèles 3D (.fbx, .obj)
- **Textures/** - Textures et materials
- **Audio/** - Sons et musiques
- **Animations/** - Fichiers d'animation
- **Icons/** - Icônes UI

Ces assets doivent être importés dans Unity dans `Assets/_Project/Art/` et `Assets/_Project/Audio/`.
